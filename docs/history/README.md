# Project history

Session handoffs, audits, plans and result write-ups that used to sit at the top of the repository
(moved here on 2026-11-24 so the front page shows the project, not its notebook). File names are unchanged:
a name you find in an old commit, issue or handoff is in this folder.

- `HANDOFF-*.md`, `PAUSE-*.md`, `STOP-*.md`: what each work session did, measured and left open, newest last by date.
- `AUDIT-*.md`: external audits and the fixes that followed.
- `RESULTS-*.md`, `PERF-*.md`, `*-2026-*.md`: measurements and design notes per model / feature.
- `old-root-files/`: stale copies of sources that live in `src/`, `include/b70/` and `tools/` (the build never used
  these copies) and a K2 hang device coredump (2026-09-28).
- The micro-benchmarks that were at the top level are in `tools/probes/`.
