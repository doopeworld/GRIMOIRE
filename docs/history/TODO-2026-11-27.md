## How to build, test, release (Tower)
- Engine dev build: copy changed files to `grimoire-runs/ink-1123/src/tools/`, then
  `docker run --rm --name ink-1123-builder --network none --cpuset-cpus 2-13 -v $PWD:/work -w /work grimoire-dev:latest bash /work/build_ink.sh`
  (never while a server from that directory runs: it overwrites the running binary).
- One card: `run_ink.sh TAG mtp /work/code2.txt 4096 64 384 2048`; BetterBench A/B: `ab_ink.sh "tag:ENV=V" ...`
  (CHUNK=4096); every `INK_*` variable is passed into the containers.
- Release: `grimoire-runs/ink-rel-1126/build_ink_rel_1126.sh` (G31 + G21), Dockerfile `grimoire-runs/image-ink-1126`,
  `ink-1123/validate_ink_image2.sh IMAGE TAG` (Ian's template layout), save + `gzip -6`, `tools/bench/upload_release.py`.
